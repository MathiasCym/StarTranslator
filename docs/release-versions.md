# 历史版本编号

以增量更新及国内小包分发的引入作为 2.1 系列起点。2026-10-20 起，更新记录及发行页统一使用下列展示编号；各版本原发布日期和实际改动保留。

| 展示版本 | 原发行编号 | 主要变化 |
| --- | --- | --- |
| 2.1.0 | 2.0.10 | 增量更新、国内小包分发、安装校验及回滚 |
| 2.1.1 | 2.0.11 | 逐段翻译与内容检查、报告选择、替换进度 |
| 2.1.2 | 2.0.12 | 小更新启动修复、独立格式对照、逐页预览 |

| 2.1.7 | 2.0.17 | Word 可见文字覆盖、超链接保护、纯色背景 |

阶段重排时的正式软件版本为 **2.1.7**，其后按 **2.1.8**、**2.1.9** 等补丁编号继续；当前版本以项目首页及 `package.json` 为准。

历史安装包已经分发，程序会核对内部版本、文件摘要和增量基线。因此历史发行页采用“2.1.x（原2.0.x）”标题，原 Git 标签、下载文件名、包内版本及校验清单继续保留。编号调整不改变软件功能，也不会重建旧安装包或切断旧版升级。2.0.17 对应的历史内容已合并在 2.1.7 更新记录中；当前正式 2.1.7 发行版另保留其原有标签和附件。

仓库中的更新记录即时使用新展示编号。已安装软件的“关于”读取随包附带的本地说明，该说明随下一次正常软件更新带入，不直接改写现有安装文件。

后台维护入口为 **Align historical release display versions**。它只修改 GitHub 和国内仓库中已有发行版的标题与说明，修改前后核对标签、发布状态、日期、目标提交及全部附件元数据；不创建、删除或重新上传发行附件。映射来源是 `.github/release-display-versions.json`，维护脚本和测试位于 `.github/scripts/`、`.github/tests/`，不会触发产品重新构建。
