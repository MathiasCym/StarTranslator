# DocuTranslate 参考与采用范围

参考项目：https://github.com/xunbu/docutranslate

研究基准提交：`01f041549549271a7fdb3459f6972db155954679`。查看了中文 README、服务层、翻译基础层、SDK、依赖清单和 Windows 打包工作流。研究副本位于 `reference-docutranslate/`，仅供对照，不进入安装包；星译官新增实现为独立编写，没有将其执行程序或代码模块并入现有后端。

| 参考内容 | 星译官采用方式 | 保留的现有约束 |
| --- | --- | --- |
| 非阻塞任务、任务状态与日志隔离 | 有界后台队列；`task_queue.submit/wait` 提供异步调用；最多同时运行 2 个任务，32 个运行或待处理任务 | 翻译、校对、人工确认、历史记录仍使用现有流程 |
| 请求并发 | 按页并发翻译，页内保持顺序和上下文；校对最多 3 路；整个进程最多 4 个模型请求 | XML 写入按原顺序进行；数字、样式、版式检查继续执行；可关闭并发加速 |
| Web / 局域网 | 独立上传网关，浏览器直接使用；桌面软件可打开独立的共享工作台窗口 | 原本本机模式保留；模型配置、文件浏览和维护接口不开放给局域网 |
| 双语输出与对照 | 采用已有 OfficeCLI 生成只读整页预览，左右显示原稿与当前结果，支持同步翻页、滚动及缩放；仍保留文字对照检索 | 不在 PPT 中插入双语文字、不挤占图片和图表；实际排版由原 Office 文件承担 |
| 小体积发布 | 浏览器客户端免安装；桌面包移除非中英 Chromium 语言资源和 Python 字节码缓存 | 保留 Electron、Python、OfficeCLI 和离线修复副本；不使用额外二进制压缩器 |

项目 README 的“小于 40 MB”是其自己的发布方案描述，不能视为星译官桌面安装包的目标或实测结果。它的构建工作流采用 PyInstaller 和 UPX；星译官保留已有桌面窗口及完整修复能力。性能测试用模拟响应测并发收益，不代表公司模型或外部 API 的实际处理速度。

新增共享界面沿用星译官的蓝色玻璃风格与人物形象。UI UX Pro Max 查询提供了响应式布局、键盘焦点、可读字号和减少动态效果的检查建议；不采用其与当前产品不匹配的营销首页布局。
