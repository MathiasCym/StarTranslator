# Word 可见文字与结构保护

过去的安全检查只要发现段落中含域指令、绘图或对象，就把整段正文排除。即使模型补译和结果校验不断加强，这些文字仍不会进入翻译。Word 文本框也曾只登记为人工处理范围。对此必须在读取与写回层修复，而不是增加模型重试次数。

`backend/extract/word.py` 为读取、翻译和校对导出提供同一遍历。普通段落保持原定位；复杂段落按域、链接、书签及对象的边界建立文字片段，同一原段落的所有片段共同提供语境。写回仅替换该片段拥有的文字 run，不能复制或删除域指令、链接容器或绘图对象。超链接显示文字可翻译；链接目标保持原样。真正由 Word 自动计算的域结果单独保护，不阻止相邻正文翻译。

遍历覆盖正文、物理表格单元格及嵌套表格、内容控件、各类页眉页脚、Word 文本框、脚注及尾注。脚注和尾注保留原部件及编号结构，输出时只同步文字。未遍历到的可见中文登记为未处理范围，不能冒充完成；删除修订中的文字不属于当前可见正文。图片中的像素文字仍不属于可编辑 Word 文本，需要单独处理并明确提示。

`tests/test_word_coverage.py` 验证含域正文、两种超链接、动态日期及页码保护、文本框尺寸、图片与关系文件、内容控件、嵌套与合并表格、脚注，以及翻译后继续校对和替换。测试使用合成文本和离线模型，不包含用户资料。真实材料另在私有目录验证覆盖率与结构，不进入公开仓库。
