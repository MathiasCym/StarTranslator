# 术语库分享

在“术语库”右上角选择格式，点击“导出词库”。默认的 JSON 词库文件适合直接交给同事；Excel 表格适合在表格软件中增删改，再导回星译官。导出包含全部词条及当前完整的编辑内容，不受搜索筛选影响，也不会替代正在编辑的词库。

同事收到文件后打开“术语库”，点击“导入词库”选择文件。也可同时选择多份 JSON、Excel、CSV 或 TSV 词库。导入会保存当前完整的编辑内容及合并结果；取消选择不会改动词库。

同名同译法会补充别名、候选写法、已确认错译和备注。不同标准译法，或别名与错译标记有分歧时，保留当前词库内容，并在“查看导入差异”中列出；点击“查看本机条目”可以继续编辑。重复导入相同文件不会反复增加词条。

Excel 保留六个常用编辑列；已有的内部确认信息和来源信息保存在隐藏列中，便于完整交换，请保留隐藏列。多条别名通常每行一条；含逗号等容易产生歧义的写法会以 JSON 数组保存在对应单元格中，避免拆分成错误别名。

导入任一文件无效或有缺少中英文的词条时，本次不会写入。请按提示补齐表格后重新导入。共享主词库被别人修改时也会拒绝覆盖，保留当前编辑内容供核对。词库副本通过文件分享，不需要登录或额外服务。
