PDF 页面对照从任务保存的不可变原稿快照读取页面，通过 Windows 自带 PDF 渲染器生成图片，不再调用文字提取和正文阅读预览。原件不要求安装 Office。英文侧继续读取当前输出文件，Word/WPS 的实际页面与兼容预览边界保持不变；两侧分别显示页数，文字对照继续用于搜索。此改动不改变 PDF 翻译输出、Word/PPT 写回或模型格式审查。

每个页面按原稿内容摘要和页码惰性缓存。读取失败显示原件错误，不静默切回排版不同的正文；加密、越界及损坏缓存可明确识别。真实 21 页本机样本的第 1、15、21 页已使用产品入口渲染，图片、标题和页码保留，原稿及输出摘要未变；重复查看没有再次启动渲染。离线测试还覆盖快照、内容变化、无文字页面、裁切／旋转信息传递及组件隔离。样本、页图与诊断仅留在忽略的本机 QA 目录。

完成页在统计下方显示下一步及待确认建议数，并直接打开原有校对报告。零建议、全部应用与暂存待保存分别表达，保存后仍可查看；未采纳建议不会被算作处理失败。局域网提供定位至报告并转移键盘焦点的按钮，建议数变化会刷新。四种桌面尺寸以及 480/900px 局域网窗口已验证无按钮遮挡；实际应用全屏与默认窗口检查通过。
