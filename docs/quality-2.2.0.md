维护者指定目标为 2.2.0。先完成 Word、PDF、PPT 实际翻译、校对及保存复测，再添加词库人名分类。正式发布、安装包与国内增量验收另依 RELEASING.md 记录；本文件不以源码测试替代交付验收。

## 格式边界

| 范围 | 本版处理 | 继续保持的保护 |
| --- | --- | --- |
| 共用 | 月份与日期区间、英文数量等价、型号与年份间逗号的事实识别；真实活动进度 | 错误数值、重复数量、单位、型号、网址变化仍拒绝；保存后重新扫描中文 |
| Word | 目录可见标签、中文编号、跨页正文表格及预览分页 | 域指令、页码引用、书签、超链接、图片和未修改的包部分 |
| PDF | 源文字层连字仅允许安全恢复空格；原链接和原页跳转另存可点引用 | 使用源格式选择策略，导出 DOCX 不影响策略；不能借此放宽其他格式型号检查 |
| PPT | 不引入 Word 表格重排或 PDF 连字例外 | 整页语境、逐样式映射、颜色加粗与字体层次、图表、原生渲染、模型版式检查 |

`backend/translation_policy.py` 明确按源文件选择专用校验；同一连字文本在 PDF 可恢复空格，在 Word/PPT 仍按严格标识符检查。正反例同时保留，不能靠删除某类格式检查提高通过率。

## 人名分类与界面

本机完整后端回归 399 项通过，安装与更新检查 116 项通过；词库筛选、保存后重新打开、紧凑窗口下的分类详情、真实全屏层及默认窗口另行检查。正式安装包仍须在全新目录验证同一批修复。

- 旧词条缺少分类时按普通术语读取，默认字段不改变旧 JSON 与断点上下文标识。
- 人名分类随 JSON、Excel、CSV、TSV、列表/表格编辑及团队合并保留；旧表缺列时可安全扩展，保留自定义列。
- 旧导入不会擦除已有的人名分类；维护者可在界面主动改回普通术语。未确认词条仍是线索，不把分类当作确认状态。
- 全屏对照用实际主界面入口验证，覆盖结果页和报告页。词库分类选择、筛选、保存及表格视图通过桌面自动检查，保持现有窗口比例。

“未检出中文”指本次实际保存文件及所测结构的结果。图片、扫描页、代码、受保护动态域或模型持续不可用时仍明确提示未覆盖范围并保留有效文件，不通过删字、改坏网址、隐藏建议来制造完成结果。
