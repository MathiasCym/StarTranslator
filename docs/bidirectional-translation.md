# 自由文本与中英双向翻译

## 使用

- 首页“文本翻译”打开独立窗口。选择中译英或英译中，输入文本后开始；支持复制译文及交换文本。每次最多 20,000 字符，长文按原段落拆分并保留换行。
- 文档“翻译”中选择中文→英文或英文→中文。继续使用既有文件导入、参考材料、PPT 忠实／压缩模式、输出位置及翻译并校对功能。
- “校对”中选择英文或中文。中文语义审校需要开启深度审校；关闭时明确说明未执行语义检查。
- 局域网工作台使用同样的方向选项和文本窗口，复用共享电脑已配置的模型及术语库。

## 质量与恢复

自由文本每段经翻译、事实校验和原译对照复核后才标记完成。服务中断、取消或内容未通过时保留已完成部分；重试仅处理未完成段落。改变原文或方向后不能挪用旧任务结果。文本任务只在当前后台进程的有界任务队列中保留，不写入文档历史或持久断点；退出程序前请复制所需文本。

文档英译中与原中译英的目标语言策略分开。原中译英继续严格检查中文残留，英译中不运行清除中文的修复；数字、单位、型号、链接仍校验，样式由模型按语义映射。无法可靠映射的段落保留原文并提示，不能按字符比例冒充格式继承。图片与对象使用既有各格式写回保护。

英译中翻译和中文审校分别使用带方向的独立断点，源文件、内容、术语、模型及策略变动会影响复用。历史恢复保存方向，不能将中译英断点当作中文译文。中文校对建议由用户确认；保存沿用冲突保护、逐项替换、进度与当前保存稿对照。

术语只召回相关条目，英译中不将全部英语词条机械倒置。相同英语对应多个中文时保留多义信息，由模型结合语境判断；姓名分类继续参考已确认拼写，错误别名不作为反向标准。

2.2.7 起增加语境中的自然人识别：使用已确认的人名词条，没有已确认中文名时保留英文拼写，不猜写汉字。翻译、中文审校及断点复用都复核姓名。Word/PPT 的颜色和加粗按中文对应词复核，固定行内标签则在保留事实和标签顺序的前提下调整中文语序；不按字符比例分配强调。

PDF 只允许补回空白，不改写文字层原有的非空白字符；逻辑段落保留，句内物理折行合并。连在普通英文词后的数值采用独立的事实校验视图，不把 `is2.5 mm` 当成型号，也不放宽真正型号、单位、网址和邮箱保护。该恢复不进入 Word/PPT 原稿处理路径。

保存时重新读取实际文件。未完成翻译的位置继续报告；可以保存有效部分、从断点继续，或在报告中明确补正后保存。只有所有源文件的当前保存稿、审校及内容检查都已完成时，历史才取消相应的未完成标记；真实断连、取消和保存错误不会因此隐藏。

## 范围

英译中覆盖现有可编辑文档：Word、PPT、PDF 文字层、Excel、TXT、Markdown、HTML、JSON、EPUB 和字幕。保留 JSON 键、公式、HTML 属性、字幕时间轴、链接目标等非正文信息。PDF 输出重新排版的 Word，英译中暂不改写图片内英文或完整还原复杂原版式；这些限制在输出提示中保留。PPT 英译中仍执行 PowerPoint 实际页面与模型版式检查，不能将无法渲染或无法看图当作通过。

## 已验证

2.2.7 源码完整后端回归 569 项、安装更新检查 116 项及自动重启专项通过。实际公司模型多轮使用合成材料测试全部 13 种扩展名，最终实际保存稿、内容及结构复核通过；Word 两页、PDF 转 Word 两页及 PPT 三页完成原生渲染检查。额外的 PDF 空白配置复测通过；12 种扩展名的文字翻译和中文审校断点在禁止模型请求下完全复用。公共质量工具从头处理及零请求恢复、自由文本中英双向翻译另行通过。PPT 页面图像复查不包含在零请求复用结论中。该样例验收不代表所有复杂材料均无翻译问题，未完成部分始终明确提示。

界面验证使用实际应用入口，涵盖窄窗口、桌面／局域网文本编辑器、方向交换、后台任务关闭后重开及全屏对照。正式构建、国内小包及旧版实际升级进度见 [2.2.7 交付验收](validation-2.2.7.md)。
