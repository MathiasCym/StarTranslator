# PPT 字号与遮挡修复（2026-10-19）

本轮基于 2.0.15，针对压缩译文仍过小、文本间相互遮挡的问题。翻译内容、参考材料、数字与单位校验、断点、建议确认及文件保存规则保持原有流程；此处修改文字排版与逐页检查。

## 已确认原因

- 同页只按原始字体、字号和粗体分组，最窄的文本框会决定整组字号，使空间宽裕的文字一起缩小。
- 多段文字被分配固定的中文段落高度，前面的英文需要换行时无法使用后面的空白，并额外加入空白来维持旧位置。
- 视觉复查重跑全部已翻译文字，并把已缩小字号当作新的原始字号，可能再次缩字。
- 模型缺少原稿字号参考；旧规则限制恢复字号的倍率，并且只允许向右、向下扩大区域，居中标签难以合理扩展。
- 只比较框的大小不能发现原框内字体变大产生的新遮挡；连续处理多个建议时，旧的相邻文字测量也不能代表刚修改的文字。

## 修复原则

- 每个文本框独立适配，多个段落共享框内高度。相同源样式的近似可行字号再协调，拥挤的个别框不拖小整页。
- 为下方正文和前景图片预留实际位置；不能因为字体估算认为中文已挤到相邻区域就跳过保护。不把空装饰框误当成正文障碍。
- 图像复查只重新处理明确指出的问题区域，限制机械缩字。模型结合原稿字号及完整页面决定字号、换行与可用区域。
- 允许模型小幅移动和双向扩展文字区域；程序逐项校验页面边界、新增遮挡、最终文字尺寸，记录获准的文字位置与大小。包结构校验只放行这几项明确批准的数据，图片、表格、图表及其他位置的保护不放宽。
- 同时检查文字实际占用范围、未变框内的新遮挡和连续调整后的相邻文字。重新渲染比较实际效果，逐页保留更好的结果；较差页面回到之前的完整页面，不连带撤销其他页已验证的调整。
- 某页图像检查返回错误格式时，该页有限重试；持续失败仅列该页待核对，其余页面继续，不将局部格式异常扩大为整轮失败。
- 不以统一固定字号强行放大全文；复杂图表、旋转对象等仍可能需要人工确认。无法解决的局部问题明确保留，不导致整份文件丢失。

## 验证

回归入口仍为 `tools/run-regressions.py`。新增多段压缩文字共享空白、窄框隔离、原框内放大遮挡、恢复过小字号、同字号换行扩展、移动边界与包位置保护、渲染重叠及避免反复缩字等用例。

本机实际材料只在独立副本中验证，保留现有英文与图片，通过已授权公司内网模型检查完整页面。材料、图像、模型配置、原始响应和日志保存在忽略的 `dist/qa/readability-216/` 内，不进入公开源码。具体通过结果及正式发布状态以本次发布记录为准。
