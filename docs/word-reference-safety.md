# 书签保护与当前保存稿对照

2026-10-22，合并到当前 2.2.1 源码，随下一次常规产品更新交付；没有替换正式安装包或另起修订版。

## 原因与处理

本次真实 Word 原稿已经存在两个缺失目标的页码引用。翻译保留了原书签及域指令，但此前保存流程没有识别这种输入问题；Word/WPS 在实际打开或渲染时刷新引用，才出现书签错误。另一份 PDF 原稿的目录已直接印有错误文字，旧流程又把诊断翻译成英文。两种情况必须分别处理。

`backend/word_references.py` 根据包内真实书签检查内部 REF/PAGEREF/NOTEREF，只有目标不存在的引用才锁定刷新。正常域及书签保持不变，缓存可用时保留；缓存已经是错误字符串时标记为“—”。保存提醒指出目标缺失及缓存未经核实，不保证缓存仍是正确页码，不根据相邻标题猜造目标。Word 写回原有的链接、域、书签、嵌入对象严格结构检查仍先执行，没有放宽保护。

PDF 仅在已识别的目录行处理带编号、引导线或制表符的末尾诊断，保留标题和格式，将无法确认的页码标为“—”。正文讨论这类错误的句子、有效页码及普通英文不删除。该逻辑也覆盖已有 DOCX 中的静态目录错误。

问题通过翻译结果的版式提醒、校对范围提示及保存提醒展示，不当作未译正文要求重译；没有校对建议时直接保存也执行保护。原稿、图片、链接目标保持不变。PPT 专用翻译和版式路径没有改动。

## 对照入口

桌面输出页在当前输出路径及打开文件按钮旁提供中英对照，按所选输出记录定位。首次保存前明确显示“初稿”，应用建议后显示“已保存稿”；连续保存替换该文件的旧输出记录，多文档各自保留当前版本。校对报告和局域网端使用同样的当前文件关系，保存后刷新对照元数据。

## 验证与边界

- 专项覆盖复杂域、简式域、有效书签、静态错误跨样式片段、正文负例、PDF 提取及规则校对、无建议直接保存、翻译完成状态与链接保留。
- 最终完整后端清单 494 项：491 项在隔离环境通过；另外三项 Windows DPAPI 检查受沙箱身份限制，使用临时目录及虚构密钥在正常 Windows 会话单独复测，三项全部通过。桌面与局域网界面检查通过，另核对实际应用入口的全屏对照。界面证据包含初稿、保存稿、多文件切换及连续保存。
- 两份真实输出副本使用普通产品 `open_office` / `save_office` 保存，由独立 Word/WPS 实例只读渲染。实际为 17 页及 18 页，全部页面文字中书签报错为 0，目录页图另行核对；原输入哈希、图片及所有关系文件、书签和域指令均保持一致。每份两个原稿问题仍保留提醒。
- 真实材料仅在忽略的 `dist/qa/word-bookmarks-2026-10-22/`，没有上传模型或公开仓库。本次没有重新执行整份模型翻译，不能把保存与渲染验证写成重新翻译验收。

这项修复不重建原稿缺失的章节，不保证已有目录的缓存页码正确，也不将有缺陷的输入冒充目录已经全部核实。Microsoft 对书签失效的说明见 [Troubleshoot bookmarks](https://support.microsoft.com/en-gb/word/troubleshoot-bookmarks)，域锁定语义见 [FieldChar](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.fieldchar?view=openxml-3.0.1)。
