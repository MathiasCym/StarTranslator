- `package.json` 内部包名改为 `startranslator`，用户数据使用 `%APPDATA%\StarTranslator`。安装应用 ID 和升级身份不变。首次启动将旧目录整体改名并建立兼容链接；词库、密钥密文、历史与断点的绝对引用继续可用。数据占用或两个独立目录并存时保留旧数据并在界面提示，不合并或覆盖。显式测试路径及安装、渲染模式不迁移真实数据。
- 6 项目录测试包括精确保留、旧引用、幂等、占用、兼容链接失败回滚、双目录和隔离路径。`tools/check-user-data.cjs` 从真实应用入口启动自己的旧目录，实际后端返回新词库路径；2,515 条词库、模型配置及历史引用通过，原密文与设置保持原字节。真实用户安装和配置未改动。
- 公司官方表源摘要与原英语导入一致；新增 `glossary/multilingual.json`，全部 1,965 行在 8 种语言上的写法独立保留，不按中英配对去重而丢弃其他语言差异。中文、英语各 1,965 项；西、法、日、葡、俄各 1,883 项；韩语 1,882 项。空项不生成。原表不修改、不上传。
- 多语言资料提供独立 GET 接口和只读窗口；普通翻译、审校、团队提交、个人中英词库及断点身份均不引用多语言资料。4 项后端专项及全部语言实际 UI 搜索、分页、480/1024/1280px、Escape 返回焦点、原词库摘要不变通过。
- 25 个模型配置保存、重载、切换、修改、删除和密钥读取通过；界面不再显示上限，长列表只在配置区域滚动。
