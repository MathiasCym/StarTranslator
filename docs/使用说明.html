星译官 · 使用说明

LED 行业中英文技术文档翻译与审校助手　|　诺瓦星云深圳分公司

一、安装与启动 二、配置模型（每位使用者用自己的密钥） 三、开始审校与翻译 四、术语表格 五、常见问题排查

一、安装与启动

  1. 双击安装包 星译官 Setup 1.4.7.exe，按提示完成安装（默认安装目录为英文 StarTranslator）。
  2. 从桌面或开始菜单打开「星译官」。首次打开会在本机自动解压运行环境，需等待数秒。
  3. 窗口右上角的状态灯（顶栏最右侧的圆点与文字）此时多为灰色或黄色，属正常——因为还没有配置模型。下一步先配置模型。
无需注册账号。本软件不使用登录账号，也不内置任何密钥；模型由使用者各自配置。

二、配置模型（每位使用者用自己的密钥）

星译官本身不带密钥。每位使用者需要自己申请一份模型接口密钥，并在软件里填写一次，之后软件会记住本机配置。密钥只保存在你自己的电脑上，不会上传、不会随软件分发。

2.1 申请密钥

申请密钥需走公司 IT007 流程。通过该流程提交申请后，你会得到一份 API Key，以及接口地址与可用模型名称。若不清楚所需模型或用途，可一并向 IT / 维护同事确认。

拿到后请记下三样东西：

  • 接口地址：形如 http://llm.novastar.tech:31000/v1。
  • 模型名称：公司可用的模型名，例如 local-plus、local-fast 等。
  • 接口密钥：申请到的那串 API Key。

2.2 在软件里填写

  1. 点击主界面顶栏右侧的「模型设置」按钮（在「术语表格」与「关于」之间），打开「模型连接」窗口。
  2. 「配置名称」可填一个便于识别的名字，例如「公司内网」「个人 API」。
  3. 「连接方式」下拉选择：公司内网模型选 公司内网模型；其它 OpenAI 兼容服务选 其他兼容接口；本机 Ollama / LM Studio 选对应项。
  4. 「接口地址」填上一步拿到的地址。
  5. 「模型名称」填上一步拿到的模型名。
  6. 「接口密钥」粘贴你申请到的密钥。
  7. 点击保存并使用。顶栏右侧的状态灯会自动检测，变绿即表示连接成功。
关于密钥的填写规则：密钥输入框不会回显已保存的密钥。若只是想修改模型名或地址，密钥留空即可（留空表示不改变已存的密钥）；只有粘贴了新密钥才会覆盖。

2.3 保存多个配置，一键切换

窗口顶部会列出你保存过的连接配置，不设数量上限。每个配置连同它的密钥一起记住，切换时无需再输入密钥：

  • 点某个配置的「使用」，立即切到该配置，状态灯自动检测。
  • 点「编辑」可修改名称、地址、模型；密钥留空表示保留原密钥。
  • 点「删除」移除该配置（连带其中保存的密钥）。
  • 点「新建配置」填写新的连接；已达 5 个时需先删除不用的配置。
安全说明：保存的密钥在本机经 Windows 系统级加密（DPAPI）后再写入配置文件，与你的 Windows 账户绑定——文件被拷到别的电脑、或被本机其他 Windows 用户读取都无法解密。软件界面不回显密钥明文，日志也不记录它。若系统不支持该加密，窗口内会明确提示密钥以明文保存。加密挡不住以你本人账户运行的恶意程序，这与浏览器保存密码的防护边界相同。

2.4 状态灯含义

状态含义
绿色　模型已连接接口可访问，且所选模型存在，可以开始审校。
黄色　状态待确认 / 加载中服务在线但模型尚未就绪，或该服务不支持轻量探测。开始审校时会真正验证。
红色　模型未连接地址、密钥或网络有问题，见第五节排查。

三、开始审校与翻译

审校（术语校对）

  1. 在主界面把 Word / PPT 文档拖入导入区，或点击选择文件。
  2. 选择中文或英文审校方向，点击开始审校。
  3. 审校完成后生成报告，逐条列出可疑译法及建议。命中的「已确认错译」会被自动勾选，可自行取消。
  4. 确认要替换的条目后，另存导出修订后的文档。

翻译

  1. 导入中文文档，选择翻译。
  2. 生成英文译文后，可选择继续做一次校对。

四、术语表格

团队可连接一个共享的术语文件（Excel / CSV / JSON），多人共同维护词库。

  1. 打开「术语表格」，点击连接表格文件选择共享词库；或点当前词库查看内置词库。
  2. 在表格中直接增删改术语，支持搜索与分页。
  3. 点击保存表格写回文件；保存前会检测冲突，并自动生成 .bak 备份。
内置词库为只读，不能在软件内改写。多人使用云盘同步同一文件时，保存后请点「刷新」；这不是实时协同。

五、常见问题排查

状态灯一直是红色

提示可能原因与处理
授权失败密钥不正确或已失效。确认粘贴无误，或经 IT007 流程重新申请，再到「模型设置」里粘贴新密钥保存。
模型未连接 / 无法访问接口地址写错，或不在公司内网。确认已连公司网络（或有线 / VPN 状态）。
所选模型不可用模型名称拼写与上游不一致。用提供方给出的准确模型名。
连接超时网络到模型服务不通，稍后重试；若持续，联系模型服务提供方。

能连上但审校结果不对 / 报"结果被截断"

多为模型返回异常或文档过大。可先减少单次导入的文档量，或更换可用的模型再试。

换了一台电脑，软件连不上

密钥与模型配置保存在本机。换机后需在新电脑上重新打开「模型设置」，填入你自己的密钥与地址保存一次即可。

想用本机运行的大模型

先启动 Ollama 或 LM Studio 并加载模型，然后在「模型设置」里选对应的本机模型项，填写其本地接口地址（如 http://127.0.0.1:11434/v1）与模型名称。
