# 自动文档质量检查与重复验收

这份说明区分软件内自动执行的检查与人工发布验收。日常处理不能依赖维护者或编码代理逐页打开文件。当前实现不增加版本、不自动发布。

## 正常处理中的闭环

PDF 翻译和翻译并校对共用以下产品路径，桌面和局域网端均调用同一后端。

1. 文字层按 PDF 原页语境翻译，校验数字、单位、型号和受保护地址；有限补译后仍有中文时保留有效内容并提示。
2. 位图由本机 OCR 定位、视觉模型核实后翻译；只在安全区域改写，验证区域外像素及前后图。读取失败、OCR 不可用、定位失败或不安全背景不能被计成“没有中文”。无可读取文字和位图、却仍有绘制内容的页面也要报告。
3. 写出 DOCX 后重新读取文件，核对可编辑中文、图片像素与几何、链接目标、书签和页间跳转。基线来自写入前已通过核验的文档，不是保存后重新抄一份文件来与自身比较。
4. 使用本机 Word/WPS 生成实际页面，检查渲染文字是否可能缺失，对每页进行 OCR 和视觉核实。OCR 疑似必须逐项处理，整页另查 OCR 漏掉的中文及明确的裁切、遮挡、无法阅读问题。没有实际页面时不以兼容 HTML 预览充当通过。
5. 校对建议应用后的另存、覆盖、再次保存，以及直接校对 PDF 后保存为 Word，均重新进入保存文件检查。关闭模型审校的规则检查不会擅自开启模型调用；无法完成的视觉检查明确提示，文件仍允许保存。

保存结果中的 `output_audit` 给出结构检查、实际页数、检查页数、复用页数和逐项问题。未检查、检查发现问题、全部通过是不同状态；保留原图或保留文件不代表通过。输出复查的问题在报告和保存结果中可见，不仅写在调试日志中。

## 实际页面与断点

每次保存检查都会创建新的原生渲染快照，避免同一 DOCX 在 Office 或系统字体变更后仍误用旧页图。通过的模型结论只在新页图像素、可见文字、模型身份和检查策略一致时复用；有问题或检查失败的页面不保存成成功断点。中断后可复用已完成的正文、图片及页面，继续未完成部分。

Windows 页图实际像素可能受显示缩放影响。只对 OCR 和视觉模型的识别副本规范化到支持的尺寸，并保持两者使用同一坐标空间；不调整文档字号、实际页图或界面缩放。原生渲染临时页图由检查器负责清理，不为每次保存积累一份整文档图片缓存。

没有 Word/WPS、没有中文 OCR、模型不支持图片、连接失败或响应缺项时，保留有效文件并明确列出未完成检查。不会用空响应、缺项或“没能识别”推断没有中文。逐页问题不阻断其他页面及英文审校；取消和外部文件修改仍按原有保护规则处理。

## 无需人工干预的验收入口

使用 `tools/check-document-quality.py` 执行普通软件流程。它不包含客户名称、页码特例、预设译文或模型响应，也不会替软件修图或逐页修改结果。测试配置、词库副本、断点、输出和机器结果均在专用证据目录；不改正常安装或用户配置。

下面示例中的文件路径应换成已获授权的测试材料。`--allow-model` 表示允许发送所选文件到配置的模型；涉及客户材料时先取得相应授权。

```powershell
.\python-runtime\python.exe -X utf8 -B tools/check-document-quality.py --source "D:\QA\sample.pdf" --evidence dist/qa/document-quality/fresh --allow-model --apply-suggestions
```

`--source` 可重复指定，分别检查 Word、PDF、PPT 等格式；PDF 的专用检查不进入 Word/PPT 处理路径。`--expected-host` 可限制模型目的主机，配置不符即拒绝发送。只有已明确授权使用公司模型的测试才使用 `--company-model`，该参数不会改用户配置。

从头验收必须用新目录，不复制既有断点；机器结果记录 `mode=fresh` 及正文复用数。随后单独复测恢复：

```powershell
.\python-runtime\python.exe -X utf8 -B tools/check-document-quality.py --source "D:\QA\sample.pdf" --evidence dist/qa/document-quality/fresh --resume --forbid-requests --apply-suggestions
```

`--forbid-requests` 拦截模型请求，任何请求尝试都会使验收不通过，不能把失败当作零请求成功。实际原生渲染仍会运行，以便根据当前页图判断是否可复用。更换词库、模型或输入导致断点失效时，这项严格测试应失败，而不是放宽身份检查。

查看证据目录的 `latest-summary-private.json`、每轮结果和保存记录。自动验收未通过也保留生成的有效文件和原因；不能靠重复人工修补输出把结果改成通过。该目录应放在忽略的 `dist/qa/`，不得把材料、模型响应或配置发布到仓库。

## 覆盖范围与限制

2026-10-22 最终完整离线回归 483 项通过，其中输出复查专项 26 项、PDF 图片专项 27 项。覆盖保存后丢图、尺寸变化、链接或书签丢失、实际文字缺失、中文漏检、OCR 误报、模型缺项、组件不可用、高 DPI、取消、外部修改、缓存失效、规则检查不调用模型及各保存入口；包含桌面异步保存，不能只测试直接函数调用。完整测试入口仍为 `tools/run-regressions.py`。

这些检查针对可见中文、明确的信息丢失和可读性，不等于已实现 PDF 原始版式、图层组合或复杂表格的重建，也不能数学保证任意文档均没有漏检。Word/PPT 保持各自的原有格式与模型检查路径；其中尚未实施的能力不能借 PDF 检查的名称宣称完成。人工发布验收继续使用，但只负责发现软件检查的缺口，再将可复现问题纳入产品和回归测试。
