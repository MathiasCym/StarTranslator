# 本机词库的随包补全

2.2.4 的团队及随包词库虽已增加官方英语词条，已有用户仍使用原本的数据文件，首次安装初始化与原用户升级未走同一流程。2.2.5 补充默认本机词库的离线迁移，启动后读取词库时执行，无需维护授权、联网或手动同步。

`glossary/bundled-updates.json` 明确列出各补全批次。2.2.5 批次新增官方英语 1,880 条，使当时的 635 条默认库补全到 2,515 条。该批次现在绑定不可变的旧资源快照，避免未来团队词库变化导致旧迁移含义改变；它不重新恢复已经主动删除的条目。

`backend/glossary/bundled.py` 在默认本机文件旁保存完整备份及批次记录。旧追加批次只补缺失中文键，译法不同保留本机内容并记入提示；2.4 的来源修订另按下节执行。其他路径的 JSON、Excel 与 CSV 不会被自动修改。

补全使用既有编辑锁及内容指纹保护。先备份、再保存待完成记录、写入词库、最后完成记录；写回成功但记录未完成时，按预期摘要恢复记录，不重新导入。失败时不标记为完成，原词库仍可用于翻译和校对；界面提示原因，重新读取可重试。完成后的批次不再运行，用户主动删除不会反复被恢复。

测试覆盖实际 635→2,515 条、逐字段保留、显式默认路径、共享文件隔离、同名冲突、别名、重复启动、主动删除、锁冲突、备份／写入失败及中断恢复。正式包的旧版更新后首次启动还需独立验收，不能只以新安装的 2,515 条证明迁移成功。个人词库和备份只留在本机，不进入公开仓库。

## 多语言查阅

2.3.3 首次加入 1,965 行、8 种语言的独立资料；2.4 更新为新版官方表的 1,902 行、16 种语言，逐格对应，缺译保持空白。`glossary/multilingual.json` 不自动变成个人中英条目，也不以其他语言覆盖个人中英库。翻译时可引用已有语言配对；文档五语言与文本十六语言的范围见 [2.4 说明](multilingual-documents-2.4.md)。维护者已授权全部语言词条公开，原始工作簿不上传。

## 2.4 来源修订

新版官方表不只是追加词条。新批次绑定旧官方标准、新官方标准和旧默认库，按三方比较执行：本机英文仍等于旧标准时才修订；个人改写保留并列出分歧。撤下的官方项只有在来源、优先级、译法及个人维护字段均确认未改动时才移除，人名、备注或别名已维护的条目保留。

如果修订使两个原条目收敛为同一个中英标准，合并双方备注、来源和别名，不丢掉其中一条的个人信息；其他用户自有重复项不被批量清理。一次完成后旧批次被新批次取代，不会又把撤下项追加回来。还原已有记录的旧 635 条完整备份时可识别原摘要，避免当成个人主动删除了大部分条目。

完整旧默认库的实际配置副本由 2515 条更新到 2456 条：新增 2，修订 9，撤下 60，合并 1 个收敛重复原条目。其余 2445 条保持原字段，原文件有完整备份；再次读取不重写。个人词库的数量可因维护不同。31 项词库专项以及真实程序的数据目录迁移检查通过，正式包还需按固定流程核对实际旧版升级。
