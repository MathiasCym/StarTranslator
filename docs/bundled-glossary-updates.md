# 本机词库的随包补全

2.2.4 的团队及随包词库虽已增加官方英语词条，已有用户仍使用原本的数据文件，首次安装初始化与原用户升级未走同一流程。2.2.5 补充默认本机词库的离线迁移，启动后读取词库时执行，无需维护授权、联网或手动同步。

`glossary/bundled-updates.json` 明确列出每个不可变补全批次的新词键，本次包含官方英语新增的 1,880 个词条；英文及分类等数据读取随包团队词库。后续增加批次只列出新词，不重新扫描并恢复过去已删除的全部内置词条。旧版 635 条默认库可补全到 2,515 条；个人已维护的同名条目保留，所以自定义词库的总数可有所不同。

`backend/glossary/bundled.py` 在默认本机文件旁保存完整备份及批次记录。仅追加尚不存在的中文键，保留现有条目的所有字段及重复条目，不重写英文、人名、别名或备注；标准英文和已接受的别名按规范化比较。译法不同保留本机内容并记入提示。其他路径的 JSON、Excel 与 CSV 不会被自动修改。

补全使用既有编辑锁及内容指纹保护。先备份、再保存待完成记录、写入词库、最后完成记录；写回成功但记录未完成时，按预期摘要恢复记录，不重新导入。失败时不标记为完成，原词库仍可用于翻译和校对；界面提示原因，重新读取可重试。完成后的批次不再运行，用户主动删除不会反复被恢复。

测试覆盖实际 635→2,515 条、逐字段保留、显式默认路径、共享文件隔离、同名冲突、别名、重复启动、主动删除、锁冲突、备份／写入失败及中断恢复。正式包的旧版更新后首次启动还需独立验收，不能只以新安装的 2,515 条证明迁移成功。个人词库和备份只留在本机，不进入公开仓库。

## 多语言查阅

2.3.3 新增的 `glossary/multilingual.json` 保存官方表全部 1,965 行和 8 种语言，维护者已授权这些词条随软件与公开仓库发布。它是只读查阅资料，独立于本节所述中英词库补全批次；不把其他语言自动加入翻译、审校、个人中英条目或团队合并。原始 Excel 不上传，已有 2,515 条中英词库及个人修改不因查阅发生变化。
