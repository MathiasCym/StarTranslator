# 局域网协作与中英对照

一台电脑提供共享服务，其余使用者可以用浏览器，也可以在已安装的星译官中连接。两种方式均无需注册或登录。

1. 在共享电脑中配置好模型和术语库，点击顶部“局域网协作”，选择“开启共享服务”。
2. 将界面中本机的局域网地址发给同事，例如 `http://192.168.1.10:8765`。浏览器直接打开即可使用。
3. 已安装星译官的同事，也可以点击“局域网协作”，在“连接其他电脑”中填写地址。共享任务在独立窗口处理，本机任务和配置继续可用。
4. 上传待处理材料，可同时上传参考材料。任务在共享电脑执行；每次最多 30 份，每份不超过 150 MB。
5. 可提交多项任务，最多同时处理两项，其余排队。可取消处理中的任务或排队任务。关闭“并发加速”后，当前任务按顺序处理。
6. 结果提供下载和中英对照。翻译并校对时，先展示建议；可以编辑、勾选后应用，也可以明确选择保留当前译文。选择仅输出最终文件时，确认保存前不提供中间文件下载。
7. 每个浏览器会话有自己的任务列表；不要清除浏览器的站点数据，否则无法继续访问该会话的任务。任务列表在共享服务进程中保留；共享电脑重启后，已输出的文件可在该电脑的历史记录和输出位置查找。
8. 下载结果后，可以删除本次共享任务及其上传副本、参考材料和输出文件，释放共享空间。删除前会再次确认，不影响上传者电脑上的原文件。

访问需要电脑处于同一可互通的局域网，并允许所选端口连接。地址中的 `127.0.0.1` 仅供共享电脑自身使用。共享服务默认关闭；关闭共享服务后不再接受新访问，已接收的任务继续处理。退出星译官会结束服务及未完成任务，界面会提醒。

中英对照默认左右显示完整文档页面：左侧为原稿，右侧为当前处理结果，包含图片、表格和图表。可以同步翻页与滚动、调整缩放或展开查看；取消同步后可独立浏览。文字对照继续提供搜索与 PPT 页面筛选。

新任务会在本机保存一份只读原稿副本，移动原稿后仍可查看。旧记录会尝试从历史记录找到原稿；找不到或原稿已变更时会说明原因，文字对照仍可使用。页面预览使用已有文档组件，无需安装 Office；特殊效果、未安装字体和复杂公式可能与 PowerPoint / Word 有差异，最终版式仍以导出的文档为准。预览不会修改文档，也不调用模型。

点击“查看结果”会直接定位到本次结果。报告支持全选当前筛选下可处理的建议、编辑替换词，以及已替换 / 未替换筛选；切换筛选不会丢失编辑和勾选。保存后的下载入口位于报告末尾。没有建议时直接点击“保存译文”。通过页脚“联系作者”可查看并复制邮箱。

共享任务发生错误时，可下载本次任务诊断，或由共享电脑的使用者导出完整运行日志。安装完整性校验与修复继续保留；任务或保存尚未结束时禁止进行维护。
