# 词库表格格式

Excel 导出沿用新标准：微软雅黑、中英文加粗、浅色底纹、清晰边框和六个常用编辑列。各列宽度按提供的样表设置。单元格自动换行，行高依据内容调整；换行仅影响展示，不会把一个词语拆成多条别名。

从课件带入备注的零碎换行会整理成段落。短词和字母连续显示，完整说明按段落展示；保留全部文字，不改动中英文术语和别名。再次导入时，仅换行方式不同的备注不会重复追加。

导入仍按表头识别中文、英文、备注、正确别名、机翻候选和已确认错译。可先在 Excel 中编辑，再导回软件；导出会继续使用标准样式。确认信息和来源信息仍保存在隐藏列中，完整交换时请保留它们。

也支持 `zh-CN` / `en-US`、`zh-Hans` / `en-GB` 等语言代码表头。多语言表仅读取中英文与明确命名的词库字段，其他语言列不作为备注；若同时存在多个中文或英文标准列，请先保留本次要导入的一组，避免混用。导入保留原工作簿，译法分歧仍列出供确认。

连接 Excel 共享主词库后，在软件中编辑、保存会保留该表原有字体、底色、列宽和工作表名称，并开启自动换行、补足行高。新建共享表也使用标准样式。

手动编辑表格时，可选择需要的单元格，打开“开始 → 自动换行”；新增内容后若显示不全，再选择“格式 → 自动调整行高”。单个别名内部需要强制分行时不建议直接插入换行，因为别名列以换行分隔不同条目；一般使用自动换行即可。

Excel 单行最多约 409 磅。极长的备注仍可在编辑栏或单元格编辑状态中查看全文，软件不会截断文字。
