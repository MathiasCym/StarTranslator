# 主界面文本翻译与多语言检查

本批并入 2.3.5，与文件选择窗口关闭问题的修复一起交付，正在完成正式构建及国内升级验收。既有正式版、真实安装与配置保持不变。

## 功能

- 桌面点击“文本翻译”后在主界面显示原文／译文双栏。局域网页面使用相同工作区。返回文档保留文档列表、参考材料、报告、勾选与编辑状态；切回文本时保留输入、译文及任务状态。
- 源语言和目标语言可选简体中文、英语、西班牙语、法语、日语、韩语、葡萄牙语、俄语，支持 56 个不同语言组合；可交换语言与已有译文。文档文件处理仍按原有中英双向及格式专用流程执行。
- Humanizer 在正文翻译中自动应用，无开关。单词和短词组优先准确术语，不扩写成解释或宣传语。生成后仍对照原文检查遗漏、重复、限定、否定及目标语言；文风不能覆盖事实。
- 中英翻译继续使用当前中英词库；其他文本语言对引用官方表中实际存在的配对。缺项可由模型翻译，但不会增加或改写官方词条。
- 保留 20,000 字符限制、段落分隔、代码块与行内代码、数字、常用物理单位、型号及原链接；长行内代码和地址不从中间拆分。取消和断连保留已验证结果，可仅重试未完成部分。任务重试必须匹配原文与语言。首次打开会等候本地服务读取语言，失败后有明确重试提示。
