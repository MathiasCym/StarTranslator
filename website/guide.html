GETTING STARTED

星译官使用指南

从原稿到定稿，由你确认每一处修改。

本指南对应当前版本 v{{latest.version}}，介绍多格式翻译、英文审校、PPT 排版检查、断点恢复与团队协作。

安装与更新

  1. 首次安装使用 Windows x64 完整安装包，选择安装位置。
  2. 选择“仅我使用”或“所有用户”；所有用户安装需要管理员授权。
  3. 程序写入完成后进入独立的“校验安装完整性”步骤，显示检查进度与数量。全部文件通过校验后保留结果，再点击“启动星译官”，无需注册或登录。

每天首次打开软件时会在后台检查正式更新，展示重点变化；选择“此版本不再提示”只忽略该版本。也可随时在“关于 → 软件更新”中检查，软件不会自行下载或安装。

匹配受支持的旧版本且本机文件完整时，优先下载小更新包。完成大小与校验值检查后，先保存当前任务，再确认关闭并更新；更新界面显示准备、替换、校验与重启进度。增量不适用、首次安装或需要修复时，使用完整安装包。

2.0.10、2.0.11 的旧更新启动器可能无法执行已下载的小包。2.0.12 为适用的旧版本提供独立小升级程序，退出星译官后运行与原版本匹配的入口即可；它复用本机程序文件，无需重新下载完整运行环境。

国内来源优先，失败时尝试备用来源；两者的版本、大小与校验值须一致。更新成功并通过完整性检查后清理软件自己的更新缓存，手动下载的文件由你管理。模型配置、本机词库与历史保留。安装包不包含模型权重，翻译和深度审校需要模型服务，术语规则检查可离线使用。

校验与修复

文档检查组件缺失、损坏，或想确认程序文件是否完整时，可在软件内检查并尝试修复。

  1. 完成正在运行的翻译、校对或保存，打开“关于”。
  2. 点击“校验完整性”，再点击“开始校验并自动修复”。
  3. 查看检查进度；发现可恢复的组件问题时，软件会使用本版本随附的离线副本自动尝试恢复。
  4. 修复后重新校验，并检查文档检查组件能否启动；通过后可重新开始任务。

离线修复覆盖文档检查组件、固定运行文件和后端程序文件。个人文档、译文、术语库与模型配置不属于修复目标，恢复组件无需连接模型或登录账号。

如修复需要重启本地服务，而当前报告或修改尚未处理，请按提示先保存并完成处理，再次校验。任务运行或保存期间不能同时校验。

若核心程序或修复副本损坏，或出现权限不足、文件被占用等问题，请查看具体原因，必要时关闭软件后运行完整安装包。校验窗口可“导出诊断日志”；任务失败页面可“导出错误日志”。文件存在但无法启动时也会单独提示，不会将其视为修复完成。

连接模型

  1. 点击“模型设置”，选中配置查看或编辑详情，也可新建配置。
  2. 填写名称、连接方式、接口地址、模型名和服务要求的密钥。
  3. 点击“保存配置”保留修改，再点击“使用配置”切换当前连接并关闭窗口。
  4. 查看右上角连接状态；鼠标悬停可查看检测详情。
连接方式填写方式
公司内网模型新建时预填内网接口地址，模型名和密钥按公司提供的信息填写，确保公司网络可达。
其他兼容模型新建时连接字段为空。DeepSeek、Qwen 兼容接口，以及 Ollama / LM Studio 本机服务均归此类，按实际服务填写。

左侧选择用于查看与编辑；保存不会自动切换连接。“使用配置”才会切换当前模型。

软件无需登录；模型服务的密钥、额度和费用由服务方决定。密钥只需在桌面软件中配置。

其他兼容模型可选择 OpenAI 或 Anthropic 接口格式。Claude 原生接口使用 Anthropic；中转服务按其说明选择格式和密钥发送方式。旧配置继续按 OpenAI 格式使用。

文档与参考材料

主界面左侧为“翻译”，右侧为“校对”。拖入文档或点击“选择文档”，可同时添加多份文件。没有文档时保留大幅拖入区，添加后收为紧凑横栏。

文件类型处理范围
PPTX、DOCX处理可编辑文字；PPT 同时处理可编辑表格与图表文字，并检查排版。
XLSX处理文字单元格，保留公式与工作表结构。
PDF提取文字层并输出可编辑 Word；不复刻原 PDF 版式，扫描页暂不自动 OCR。
TXT、Markdown、HTML、JSON处理可读正文，保留段落、标记、链接、代码或键名等结构。
EPUB、SRT、ASS处理电子书或字幕正文，保留章节结构、字幕时间轴与样式标记。

展开“中英对照与参考材料”，加入中文原稿、英文定稿或双语资料。为待处理文档选择对应原稿，帮助模型识别明确对应的内容。软件结合同页内容、文本框结构和相邻文字理解标题及数据。

任务结束后移出已完成文档；本批全部完成时清理参考材料。未完成文档及其参考材料保留，便于继续。选择窗口支持按名称、修改时间、类型和大小排序，底部显示已选文件，并支持 Windows 文件夹与文档快捷方式。

翻译与排版

  1. 切换到“翻译”，添加中文原稿及参考材料。
  2. 按需选择输出目录；未指定时在原文件旁保存。
  3. 选中 PPT 时可选择“忠实翻译”或“文案压缩”。默认忠实保留信息，压缩模式在保留事实的前提下精简表达；问号打开独立说明窗口。
  4. 点击“开始翻译”，查看翻译、排版和检查进度。完成后打开译文，或继续校对。

翻译保留整页语境和局部样式边界，核对数字、单位、型号及漏译；可修复的问题先自动修复，有限修复后仍未完成的内容保留并标出位置，其余英文继续校对，允许保存当前文件；未译中文不会冒充完整英文或交给校对批量重译。中文原稿保留，原稿中已有的英文通常保留给校对检查。

单独翻译也会处理 PPT 格式。文字适配后进行逐页渲染与格式检查。模型图像审查需要所选模型支持图像输入；结合原稿与译稿整页图像，可提出字号、行距或文字区域调整，程序检查页面边界和新增遮挡，再重新渲染。保留颜色、加粗、字体层次及图片位置，避免一味缩小文字。

进度区除段落计数外，还显示补译、排版、渲染和检查等当前活动。段落翻译完成不等于整份文档处理完毕；格式检查条件不足或仍有未处理问题时，会明确保留提示。

材料默认来自中国、面向海外读者，涉及“国内”时结合语境明确中国，宣传用语避免夸大事实。图片内文字与复杂嵌入对象仍需人工处理，交付前请检查整体表达及版式。

翻译并校对

  1. 添加材料后点击“翻译并校对”。
  2. 开始前选择输出方式，确认后开始任务。
  3. 软件依次完成翻译与基本文字适配、英文校对；PPT 随后进行独立的逐页格式对照。
  4. 完成后点击“查看校对报告”，编辑并确认需要的建议，再保存结果。应用建议后会对实际修改的 PPT 再次检查排版。
输出方式保存结果
只输出最终校对文件中间译文暂存在本机，确认后目标目录仅保存最终文件。
保留翻译文件和校对文件保留译文，确认后另存一份校对文件。

两种方式使用相同的翻译、校对与版式流程。仅保存最终文件时，暂存译文同样参与完整处理，可从历史记录找到。个别翻译问题先有限修复，仍未解决时在报告中逐条提示，继续校对其余英文并允许保存文件；不将剩余中文交给英文校对充当完成结果。

建议不会自动应用。可选中、编辑并确认，也可不采纳建议，保存当前译文。没有建议时显示“保存译文”；分批采纳建议会更新同一份最终文件。

校对报告

已有英文材料可直接切换“校对”，添加文档、配对原稿，选择是否启用深度审校，再点击“开始校对”。

完成页先显示简要统计；点击“查看校对报告”打开完整窗口。每条建议显示原文、可编辑替换文本、原因及“已替换 / 未替换”状态。“查看上下文”显示相关文字，便于判断分行标题与统计信息。

通过搜索、类别和状态筛选定位建议，可全选可处理的建议；已替换项自动隐藏，可通过“已替换”或“全部状态”重新查看。“选中术语建议”用于只勾选术语规范类建议，不会直接执行替换。“打开所在位置”位于报告工具区，无需滚动建议列表寻找。

全文用语一致性检查识别重复原文的不同译法、术语混用以及 H2 / Second half 等标题差异，可筛选、编辑后确认。术语规范根据已确认错译给出建议，深度审校结合模型检查表达、语法与原稿一致性。模型失败、任务取消或部分段落未完成时，请查看检查范围，不能将已完成部分视为全文通过。

确认修改与保存

勾选建议，可先编辑替换文本，再保存：

  • 单独校对：可另存新文件；支持原格式覆盖时也可直接覆盖。PDF 文字层输出 Word，不能覆盖原 PDF。
  • 翻译并校对：按开始时选择的方式保存最终文件或校对文件，中文原稿保留。
  • 无需采纳建议：可不应用建议，保存当前译文；没有建议时直接点击“保存译文”。

连续应用会保留已确认修改。保存时检查文件是否被其他程序改动；如已变化，需要重新校对，避免覆盖外部编辑。替换、排版、逐页渲染与文件检查在后台执行，并显示当前阶段及进度。

保存后检查版式提示并打开结果审阅。无法写入时，关闭编辑器中的同名文档，确认输出目录可写，再重试。

处理结果时切换功能、关闭报告或返回文档页面，若还有未处理建议、未保存的编辑或暂存最终文件，软件会先确认。全部建议已应用并保存后可直接关闭报告；再次点击当前功能不会关闭结果。

原文与译文对照

在结果或历史记录中打开“中英对照”，PPT 可左右查看完整原稿与处理后的页面，包含图片、表格和图表，支持同步翻页、缩放与滚动。大文件按页生成预览，无需一次载入整份演示文稿。

切换“文字对照”可搜索原文或译文、按页面筛选并展开段落。页面预览依赖本机渲染条件，特殊字体或效果可能与文档编辑器存在差异，最终版式以导出文件为准。

历史记录与断点续传

按本日、本月、本年或指定时间段查找任务，查看原文件、输出文件与所在位置。校对和后续导出合并为同一条记录，显示替换数量、输出次数及最近输出时间。仅保存最终文件的任务在确认前记录暂存译文位置。

连接中断、取消或重启后，可从未完成结果页或历史记录继续任务，复用已验证的译文与校对结果。恢复前核对原稿、词库、参考材料、翻译方式和模型；条件不一致时不套用旧断点。首次恢复较快，可能是已验证段落被复用，并非跳过检查。

未完成的范围与原因会显示在结果中，可导出错误日志。断点用于恢复处理进度，不代替已输出文件；最终报告中的替换仍需你确认后保存。

术语库导入导出

点击“术语库”，使用列表与详情浏览或切换表格批量编辑。列表、工具栏与表格已压缩多余留白，同一窗口可查看更多词条；长备注支持换行、滚动和编辑，调整窗口尺寸不会丢失当前修改。搜索支持中文、标准英文、别名与备注。修改后点击“保存词库”，“重新读取”重新载入文件。

团队共享

局域网共享工作台

  1. 在共享电脑中配置好模型和术语库，点击顶部“局域网协作”，选择“开启共享服务”。
  2. 同事在浏览器中打开界面显示的局域网地址；也可以在已安装的星译官中点击“局域网协作”，填写地址后连接独立的共享工作台。
  3. 上传待处理文档及可选参考材料。支持翻译、校对与翻译并校对；最多同时处理两项任务，其余自动排队，可查看状态和取消。
  4. 校对建议由你编辑、选择并确认后保存，可全选当前建议；筛选时保留编辑和勾选。保存后的下载入口位于报告末尾，“查看结果”直接定位到结果区。仅输出最终文件时，确认保存前不提供中间文件下载。
  5. 通过“中英对照”左右查看完整原稿与处理后页面，包含图片、表格和图表；支持同步翻页、滚动和缩放，也可切换文字对照搜索。特殊效果或字体可能与文档软件存在差异，最终版式以导出文件为准。
  6. 下载需要的结果后，可删除本次任务与共享电脑中的文件副本，释放共享空间；原电脑上的文件保留。

两种访问方式均无需注册或登录。电脑需处于可互通的局域网并允许所选端口连接；127.0.0.1 只供共享电脑自身使用。共享服务默认关闭，退出星译官会结束共享服务及未完成任务。

每个浏览器会话有自己的任务列表，清除站点数据后无法继续访问该会话的任务。共享电脑重启后，已输出文件仍可在其历史记录和输出位置查找。共享任务出错时可导出任务诊断，完整日志由共享电脑导出。页脚“联系作者”可查看并复制邮箱，桌面和手机均可使用。

团队词库同步

  1. 在“术语库”中先保存本地修改，再点击“团队同步”。
  2. 点击“获取最新词库”，预览新增、修改和删除的词条后确认合并。词库位于公开仓库，读取无需注册或登录。
  3. 同一词条存在不同译法时，逐项选择本地或团队内容；确认前不会修改当前词库。
  4. 维护者在授权设置中一次性填写具有本仓库写入权限的授权，并填写维护说明后提交修改。可查看维护记录，了解修改内容与作者。

授权只加密保存在维护者的 Windows 账户中，不随词库共享。普通翻译、校对、获取词库和检查软件更新均不需要仓库授权。发布的团队词库可公开访问；个人文档、模型配置和接口密钥不参与同步。

共享术语库文件

将导出的 Excel 或 JSON 分享给同事，对方导入合并后保存。也可将共享词库放入网盘同步目录或共享盘，其他同事连接同一文件。同步由网盘或共享盘完成；编辑前重新读取，保存后等待同步，避免同时写入。

并发加速

翻译与校对均可开启“并发加速”。同页译法与文档写入顺序继续保留；模型不适合并发或处理更慢时，可关闭后按顺序处理。实际速度取决于模型服务、网络和文档内容。

常见问题

状态灯为什么是红色？

悬停查看详情，检查配置、服务、接口、模型名、密钥及网络。VPN 本身不会被当作失败依据，以实际接口连接情况为准。

为什么有些中文没有翻译？

图片和复杂嵌入对象可能没有可编辑文字。可编辑图表文字参与处理，其他内容需查看未处理提示并人工补充。

为什么文件读取失败？

不要选择以 ~$ 开头的 Office 临时锁文件。确认正文文件完整、能正常打开，且当前账号有读取权限。

任务未完成时，页面持续显示原因。点击“导出错误日志”保存诊断文件，其中包含版本、Windows 环境、组件完整性与最近错误记录，便于团队排查。文档检查分别提示组件缺失、无法启动、检查超时或返回结果异常。组件缺失或损坏时，先在“关于”中使用“校验完整性”，尝试离线恢复；无法自动修复时再按提示处理或重新安装。

为什么建议无法勾选？

可能已替换、原文已更新，或结构无法安全改写。查看状态与原因，必要时在文档编辑器中处理。

标题为什么不必各自构成完整句子？

PPT 标题与下一行可共同表达一条信息。例如 Exceeds 与下一行 214,000 screens 应结合阅读，无需将数字再加进标题。

在哪里查看版本说明？

软件“关于”和本网站“更新记录”均按版本列出主要新增、调整与修复。
