# 星译官静态说明网站

功能介绍、完整使用指南和历次更新记录。图片和样式直接内嵌，任意一个构建后的 HTML 都包含完整内容，没有账号、文档上传或安装包下载入口。

## 构建与查看

在项目目录运行：

```powershell
node website/build.cjs --version 2.2.3
node website/verify.cjs
node website/preview.cjs
```

直接打开或发送 `dist/星译官官网.html` 即可，无需同时发送图片文件夹或样式文件。`dist/index.html` 与 `dist/guide.html` 同样可独立打开、复制或改名；两者包含相同的完整内容，指南入口优先展示使用说明。导航全部为页内跳转，离线也可使用。

也可打开预览工具给出的本机地址。验证包括图片与原始资源摘要一致、没有外部资源依赖、完整指南和所有导航锚点存在；额外在隔离目录中进行断网渲染检查。

更新说明来自 `CHANGELOG.md`。先核对软件已正式发布，再用 `--version` 指定本次官网版本；省略时取 `package.json`。构建收录截至该版本的说明，并排除 `release-history.json` 中已重新编号的版本，不再因本机构建记录缺失而漏掉 CI 发布的版本。`dist/releases.json` 只包含版本、日期和说明，不包含安装包地址、路径、大小或校验值；构建不依赖安装包仍保存在本机。

桌面交付时，将构建后的 `website/dist/星译官官网.html` 复制到桌面同名文件，核对两者摘要，并用单文件离线查看。同步维护 `index.html` 的功能概览与 `guide.html` 的实际操作说明，不能只替换版本号。

## 发布与更新

仅将 `website/dist` 的静态内容放到既有网站托管目录。重新构建后以相同方式更新页面。桌面文件的更新与远端托管发布分别处理；未明确要求时不执行远端托管发布。

旧的 `publish.cjs`、`prepare-assets.cjs` 为此前安装包托管方案保留，不属于当前流程，请勿用于本次更新。当前预览工具仅提供静态说明，不提供安装包路由。
