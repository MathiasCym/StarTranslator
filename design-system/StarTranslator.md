# 星译官界面约定

采用 UI UX Pro Max 的玻璃质感方向，并以用户认可的旧版蓝青色风格为准。保留新版的信息结构、清晰焦点、稳定表单和阅读字号，通过半透明面板、细边框、顶面反光与局部柔光呈现薄透层次。

- 深色背景 #081320 叠加蓝青色径向光晕。面板采用半透明蓝色渐变与 10–16px 背景模糊；输入区域更深，保证内容清晰。
- 主要文字 #e8f1f9，辅助文字 #a0b8ce。主要操作采用 #23b9ed → #2786eb 渐变配 #041321 深色文字；选择态用青色边框与可读标签。
- 正文 18px，输入 17px，辅助说明 14–15px；系统字体支持中文与离线运行。
- 间距采用 8 / 12 / 16 / 24 / 32px，圆角 9px（控件）、14px（面板）。
- 文档区与任务区分栏，小窗口上下排列；结果表格与词库各自滚动，操作区保持可见。
- 所有交互显示键盘焦点。弹窗约束焦点，Esc 走既有关闭逻辑，保留未保存修改保护。
- 欢迎文档区恢复既有 6 秒流光动画；流光不遮挡文字、按钮或拖放操作。主要按钮与角色保留柔光反馈，避免全屏持续运动。
- 尊重系统减少动态效果设置，关闭动画与过渡并保留玻璃层次。业务操作、数据格式与默认窗口大小保持兼容。
- 安装与卸载恢复旧版布局、轨道装饰、蓝青渐变和按钮箭头，沿用既有升级、范围选择和进度逻辑。
- 官网采用同源品牌的浅色阅读界面，使用真实版本清单与实际下载文件，无在线上传、注册或登录流程。
