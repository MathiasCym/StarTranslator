# 星译官界面约定

文档工作台使用深蓝导航与偏冷白的工作区。文档区、表单、列表和译文以白色为底，亮蓝标出主要按钮与当前选择，金色集中在导航选中线、页签下划线和任务标题。品牌图标和角色来自维护者提供的原始图集。

- 文档任务按添加材料、设置任务、开始处理布置。任务设置内容过长时可独立滚动，启动按钮留在卡片底部。
- 文本翻译直接占用工作区，语言工具、原文和译文、复制与提交分三层。输入框焦点描边画在控件内部。
- 历史记录、术语库和模型设置是主工作台页面，由左侧导航切换。历史记录将日期、任务类别和搜索放在白色任务卡片上方。术语详情先显示当前语言的标准译法与确认状态，别名、错译及备注可展开。
- 模型设置左侧为浅蓝配置列表，右侧编辑连接与密钥，底部保存或应用。模型与术语的草稿在页面切换时保留。关于窗口在产品信息下横排维护操作，版本记录在独立区域滚动。子窗口沿用工作台浅蓝底色，内容与表单使用白色。
- 校对报告按统计、筛选、勾选、另存布置，输出与保存放在右侧。页面对照使用同一工具栏，文档本身的颜色来自源文件。
- 翻译和校对结果直接展开在工作台浅蓝底上。白色卡片集中呈现文件与当前状态，蓝色突出打开和后续操作，文件内详情按需展开，页底固定任务操作。
- 局域网协作集中显示本机共享状态、地址和连接入口。共享工作台沿用导航、文档与任务分区，窄浏览器窗口改为单列。
- 安装、卸载和原生更新保留深色底。主要控件采用高对比文字，确认对话框保留不可逆操作的后果。
- 本地测试版使用独立数据目录，先用真实 Windows 窗口和共享子窗口走查，再由维护者人工确认。
